# TaskMatch investor website — positioning and claim notes

## Strongest investor-facing elements
- Leads with the **coordination-layer thesis**, not a generic “AI marketplace” claim.
- Uses existing TaskMatch V1.0 screens and approved worker imagery, preserving the real gold / cream / charcoal / navy product identity.
- Gives **Private TM Assistant** strong visibility while preserving worker control: private context, useful intervention, editable draft only.
- Explains **Task BM** as evolving transaction state rather than academic jargon.
- Makes the authenticated **two-device Supabase realtime proof** prominent, while explicitly labeling it a technical proof-of-concept rather than customer traction.
- Translates founder R&D into a product path: continuity → ambiguity/change detection → context-aware intervention → human confirmation.
- Presents Saudi-first / GCC-next rationale without invented market-size figures.

## Claims deliberately softened
- Production-grade multilingual AI translation is not described as fully deployed; server-side Qwen translation + script preference + contextual assistance is the next milestone.
- Research manuscripts are described only as submitted to established peer-reviewed journals. No acceptance, patent, or scientific-validation claim is made.
- Company status is stated as founder-led, under development, pre-incorporation / product development commenced in 2026.
- No “best in the world,” “no competitor does this,” legal-compliance guarantee, fake user count, revenue, rating, testimonial, TAM/SAM/SOM, or customer-traction claim is used.
- Task BM / structured task record is not described as an insurance, escrow, legal or regulatory guarantee.

## Public-repo safety
The package contains only static HTML and image assets. It contains no API keys, Supabase credentials, test passwords, signing keys, keystores, APK/AAB files or private Android source.
